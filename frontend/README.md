# Ironhide frontend

Static site uploader for the Ironhide API. Vite + React + TanStack Router, built to
`dist/` and served by Nginx.

## Running it

```sh
bun install
bun run dev
```

The dev server proxies `/api/*` to the backend's control plane. The target defaults to
`http://localhost:2345`; override it with `IRONHIDE_API_URL`.

```sh
IRONHIDE_API_URL=http://10.0.0.5:2345 bun run dev
```

`changeOrigin` is on, because the backend's control routes only answer on `CONTROL_HOST`
(`localhost:2345` in a local checkout) and a browser sends `localhost:5173`.

## Deploying

`bun run build` emits `dist/`. Nginx needs to serve that, route the API prefix to the
backend, and fall back to `index.html` so the claim route resolves:

```nginx
server {
    listen 443 ssl;
    server_name ironhide.example.com;

    root /srv/ironhide;
    index index.html;

    # The control plane. The Host header is left alone so the backend's
    # onlyControlHost check still sees CONTROL_HOST.
    location /api/ {
        proxy_pass http://backend:2345/;
        proxy_set_header Host $http_host;
    }

    # Client-side routes, so /claim/<token> loads the app rather than 404.
    location /claim/ {
        try_files $uri /index.html;
    }

    location / {
        try_files $uri $uri/ /index.html;
    }
}
```

The data plane is not touched here: uploaded sites are served by the backend on their own
host suffix, which must resolve to the backend and must never serve this app.

## Notes

- `src/components/ui/` is vendored shadcn. Add to it with `bunx shadcn@latest add <name>`.
- `src/routeTree.gen.ts` is generated by the router plugin. Commit it, never edit it.
- Zip and folder uploads always send `?flatten=true`. The server only strips a directory
  when every entry shares one, so it is a no-op on an archive that is already correct and
  the only thing that makes a wrapped project directory work at all.
- There is no `/config.json`. Everything the UI shows comes from API responses.
